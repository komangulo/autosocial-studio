CORRECCION DEL AVISO "GOT IT" DE TIKTOK

Este ZIP contiene el archivo corregido del uploader de TikTok. Copia su
contenido sobre la raiz de autosocial-studio y reemplaza el archivo existente.

Ruta de destino:

src\tiktok-uploader.js

CAMBIO

Antes de seleccionar el video, el uploader busca el boton exacto "Got it" y lo
pulsa si esta visible. Tambien vuelve a comprobarlo cuando termina de cargar el
editor, porque TikTok puede mostrar el aviso con un pequeno retraso.

Despues de copiarlo, cierra y reinicia AutoSocial Studio.
